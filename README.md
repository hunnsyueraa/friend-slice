# 好友水果杀 · 静态本机纪录版

`index.html` 是已编译的单文件游戏，11 张原照片、游戏脚本和样式均内联，不需要联网加载外部素材。可放在 GitHub Pages 等静态托管中，打开在线网址游玩。也可用浏览器打开本地 HTML 离线游玩；微信不会直接执行 HTML 附件。

包含 60 秒挑战、切图碎片、连击、炸弹扣时、11 图收集、音效、战绩卡和当前浏览器的前 10 本机纪录。**本机纪录不是跨用户共享排行榜。** 不需要也不会调用原云端接口。

开发构建：若同级 `../friend-slice/node_modules` 可用，运行 `node build-static.mjs`；独立使用时先安装 package.json 中依赖。构建不会调用网络。源码仅复用旧工程的游戏逻辑、画布、照片裁剪与音效，未修改旧工程。

分享使用当前网页的完整项目路径，适配 GitHub Pages 的仓库子目录。`file://` 下不复制本机路径，也不把本机文件路径写进二维码。
